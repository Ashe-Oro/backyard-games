# Disc image provenance (Dolphin ISO)

Every component of `BackyardCornhole-BYCEAO.iso` and where it comes from. **No Nintendo retail file is
bundled** (no retail apploader, no copied `boot.bin`, no retail TMD/ticket).

| Component | Source | License |
|---|---|---|
| `sys/main.dol` | This repo's `build/boot.dol` (devkitPPC + libogc), copied byte for byte; `make iso` fails if the SHA-256 differs | Repo license; libogc (zlib-style) |
| `sys/boot.bin` | Generated by `tools/mkdisc.mjs`: ID `BYCEAO`, title "Backyard Cornhole", Wii magic `0x5D1C9EA3`. DOL/FST offsets laid out by WIT | Repo license |
| `sys/apploader.img` | Original code in `dolphin/apploader/apploader.c` + `apploader.ld`, built with devkitPPC (`-msdata=none -G 0`, freestanding) and wrapped with the standard 32-byte header by `tools/mkdisc.mjs`. It reads boot.bin → DOL header → DOL sections and returns the DOL entry, the protocol Dolphin's BS2 emulation drives (`Core/Boot/Boot_BS2Emu.cpp`) | Repo license |
| `sys/bi2.bin` | Generated by WIT 3.05a at compose time, region patched to USA (`--region USA`) | Generated data |
| `sys/fst.bin`, partition header, TMD, certs | Generated by WIT 3.05a (`wit copy … --id BYCEAO --ios 58`); fake-signed, which Dolphin accepts for homebrew images | Generated data |
| `ticket.bin` | WIT 3.05a generated homebrew ticket, retained as `dolphin/generated-ticket.hex`; its generated title key is fixed for repeatable disc bytes. No retail input | Generated data |
| `files/README.txt` | Written by `tools/mkdisc.mjs` | Repo license |

Tools: devkitPPC r51 (GCC 16.2), libogc 3.2.1, libfat-ogc 2.1.0 (pkg.devkitpro.org, SHA-256 checked against the
repo database), Wiimms ISO Tools 3.05a r8638 (`wit-v3.05a-r8638-x86_64.tar.gz`, SHA-256
`df95a14f1b4b2bd95d3111b70c6304e91d4ed3e4c7f72b1ad5306c3616d8933f`).

Exact compose command (from `Makefile`):
`wit copy dolphin/iso-root dist/BackyardCornhole-BYCEAO.iso --iso --id BYCEAO --name "Backyard Cornhole" --region USA --ios 58 --trunc --overwrite`

Game ID `BYCEAO`: `BYC` Backyard Cornhole, `E` USA/NTSC-U, `AO` maker code. The GameTDB collision check is still
open (SPEC §9 Q8). Video mode is chosen in code (NTSC only); the region letter is disc metadata.
