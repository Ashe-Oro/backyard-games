# Beer Pong smaller swat hand

Both the human and CPU glove now use a fixed uniform scale of 0.55, reducing every dimension by 45% on desktop and phones. The shared `createGlove()` factory applies the reduction once. No changes were needed in `hand-swipe.mjs`, `game.js`, or `style.css`: side entry, horizontal motion, 280 ms animation, pose, impact position, human hit radii (18 px desktop / 22 px phone), target styling, and CPU contact simulation remain unchanged. No other games were changed.

The existing browser checks now assert the reduced scale for both hands, alongside their fixed pose/scale and horizontal side-swipe checks. Phone screenshot checks also verify the reduced scale.

Inspected the desktop CPU and 390×844 human captures. The hand remains clearly visible near the ball while leaving the table readable.

Validation uses a local static server on port 8012 and the existing `/tmp/pong-chrome.cjs` adapter to launch system Chrome with Playwright. Initial concurrent human-swat runs failed around the existing short resume-and-swat window; the serial rerun passed without gameplay or timing changes.

All 12 Beer Pong JavaScript suites passed: bounce, main game, feedback, human swat, input, natural bounce, position, re-rack, CPU re-rack, throw, tournament, and swat AI. The tournament suite covers desktop and 390×844 phone. AI fixed-seed contacts remain rookie 22/1000, regular 550/1000, ace 927/1000, boss 937/1000. `git diff --check` passed. Unrelated screenshots generated by the existing test suites were removed or restored.
