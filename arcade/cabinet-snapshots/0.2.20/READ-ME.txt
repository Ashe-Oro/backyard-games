Backyard Cornhole Arcade — 0.2.20
================================================

Offline Cornhole for one shared trackball. Practice, two players, or the
standard eight-rival tournament. The Batocera cabinet uses the native Linux
build under Ports. The website and its saves are separate.

PLAY
----
The spinner no longer slides the bag; use bottom 1/2 to nudge.
Roll forward to throw, angling left or
right to aim: forward-left (1) aims left; forward-right (3) aims right.
Power is linear in peak forward speed: sensitivity-adjusted hardware counts/sec
measured over a sliding 80 ms window, capped at 100%. The opening report has no
known duration and is excluded; a valid sample needs at least 16 ms and 8 measured
forward counts. Default full-power speed is 3300 counts/sec; 1650 gives 50%.
This halves power sensitivity from 0.2.19. Distance does not grant power:
a long slow roll stays weak.

The peak is retained at release. A short fast flick can throw before the stroke
length gate: release happens when forward motion ends, after 160 ms idle, or
when windowed speed drops at least 40% from its peak after a full window.
Stroke length (20–1200 counts, default 400) is only an auto-release upper bound;
it does not set power. The forward timeout also releases an established peak.
A single report or tiny jitter cannot throw; residual motion cannot fire again.
Optional backswing spin and forward 1/3 aiming are unchanged.

Backswing is optional. Back-left (A) adds clockwise landing spin and curl right;
back-right (C) adds counterclockwise landing spin and curl left. Lean scales spin.
Straight back (B) or no backswing gives zero spin. Stale backswing expires.
Rotation affects landing, not airborne curvature; forward X still aims.

Player 1 / Pad 0, Twin USB Gamepad (0810:e001, /dev/input/event8):
  Top 1 / index 0: cycle Kobe / Slider / Normal height.
  Top 2 / index 1: flip Slick / Sticky.
  Top 3 / index 2: Reset Bag.
  Top 4 / index 6: Reset Bag.
  Bottom 1 / index 3: nudge position left by 0.05.
  Bottom 2 / index 4: nudge position right by 0.05.
  Bottom 3 / index 5: Reset Bag.
  Bottom 4 / index 7: Reset Bag.
Indices 0, 1, 2, 3, 5 are confirmed by Ashe's live presses. Top 4 = index 6,
bottom 2 = index 4, bottom 4 = index 7 are inferred from the standard Twin USB
Y X L1 L2 / B A R1 R2 grid plus unused-button observations. Top 4 was not
directly observed. cabinet-input.py still emits sorted evdev codes 288–297.
Nudges clamp to [-0.45, 0.45], cancel windup and never throw. Each press acts once.
Menus: 0/3 confirm, 1/4 back, 2/5 retain reset-key aliases, 6/7 unused.
Button 8 pauses/backs; button 9 confirms in menus and pauses in play.
Other pads retain their 0.2.17 mappings. Explicit saved bindings still apply.
Keyboard fallback: H height, F surface, R reset, Enter select, Escape pause.
F2 opens Cabinet Setup. Alt+F4 exits.

Reset Bag centers the unthrown bag and clears its windup without consuming a
throw, clearing the board, or changing scores. The gauge beside the bag shows
actual throw power and keeps the previous shot visible for five seconds.
The live board close-up is always on in play. Match and round points remain
visible; round totals recount as bags settle.

CALIBRATION
-----------
Preferences save to backyard-arcade-v9. Load v9 with speed-only factory migration;
v8, v7, v6 and v5 migrate through previousSettings, and v4–v1 through legacySettings.
Missing speed (including v8) and factory speeds 1050, 1650, 2100 and 6500 counts/sec
become 3300 counts/sec. Other custom calibrated speeds are preserved for v9–v5.
Legacy profiles also use the new defaults, with a 3300 counts/sec minimum to
avoid turning old distance calibration into a hair-trigger. Bindings and
sensitivity carry over. Only factory release gates 220, 48 and 80 become 400;
other custom gates are preserved. Factory spin 0 becomes 1; nonzero spin stays.
Current v9 profiles can explicitly choose spin 0 or a short stroke gate.

Cabinet Setup restores Full-power speed with +/-200 counts/sec adjustments,
clamped to 400–10000 counts/sec. Calibrate Trackball asks you to roll forward
firmly at a comfortable full-power speed. It sets Full-power speed to the new
peak measured speed / 0.7, then applies the same limits: that reference roll
represents 70% power, leaving headroom. Calibration leaves sensitivity alone.
Sensitivity, Wind, Stroke length, Backswing spin, bindings, Reset Settings and
F2 remain available. Reset Settings restores speed 3300 counts/sec, stroke
length 400 counts, spin 1 and the other factory settings.

Sideways spinner rolls are ignored for placement. A quiet period after each turn prevents residual motion launching
the next bag. No device is grabbed and no global controller mapping is edited.

NATIVE BATOCERA PACKAGE
----------------------
Back up the existing package and metadata. Stage and verify the Linux ZIP
outside the ROM collection before replacing its files while Cornhole is closed.
Runtime: /userdata/system/backyard-games/BackyardCornhole-linux
Ports launcher: /userdata/roms/ports/BackyardCornhole.sh
Log: /userdata/system/logs/cornhole-native.log
Music: /userdata/music/backyard-cornhole (or choose a local folder in Music).
The runtime uses a private bundled libcups; it does not replace system libraries.

The launcher releases only Cornhole's stranded virtual exit keys before handing
back to Batocera. Batocera-Support contains the separately reviewed gameStop
hook for /userdata/system/scripts/90-release-virtual-hotkeys.sh. It releases
hotkeygen's virtual keys at game exit, never physical keys or input mappings.
Keep the existing installed hook when updating Cornhole. Backups and successful
Cornhole/Sega exit tests were preserved in the cabinet's es-diagnosis cache.

The obsolete Windows/Wine package is not the cabinet's supported launcher.
Prepare a recoverable backup outside scanned ROM folders before removing it.
Do not remove other Windows games or Wine prefixes. Artwork and metadata are
prepared in media/; their installation and Favorites verification remain pending.

DEVELOPMENT AND QA
------------------
For this snapshot: node --test tests/*.test.mjs (from this directory).
The committed app -> resources-app symlink supports the test imports.
Build tooling in arcade/ is older than this cabinet snapshot; do not use it
to replace the verified cabinet application.
Optional local Mac package: node build.mjs --mac.
Browser/Electron regression scripts live in tests/. They accept NODE_PATH for
the test driver, ELECTRON_PATH for the packaged app, CHROME_PATH for Chromium,
and BASE_URL for the generated site. No test fixture is included in the game.

The build generates an isolated offline copy under arcade/dist/site. Canonical
web files are never edited. Vercel excludes the whole arcade directory. Cabinet
preferences use the standalone app's own profile. Preserve that profile during
updates so calibration, mappings, music choice and tournament progress survive.

Read BACKLOG.md for implemented work, verification and the remaining physical
playtest/installation tasks. Do not report the cabinet updated from a local build.
